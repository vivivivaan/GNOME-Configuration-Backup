  Name: Window Control
  Description: Control windows from a script, a rules file or the keyboard, on Wayland and X11.

* Scripts: a D-Bus interface lists the open windows with ID, title, WM class, PID, workspace, monitor and geometry. It can activate, move, resize, minimize, maximize, fullscreen, set above, set sticky or close a window. This does on Wayland what wmctrl does on X11.

* Keyboard: Super+Ctrl and a numpad key tile the focused window on a 4x2 grid. Every shortcut is a GSettings key that you can rebind or unbind.

IMPORTANT: the interface has no access control. Any application in your session can call it to read window titles and to control your windows. This is necessary for the intended use from shell scripts. Do not enable the extension if that is not acceptable to you.
